# Pixel Cursor Follower

A lightweight interactive cursor effect that creates a pixelated trail following the user's mouse movement.

## Features

* Pixel-based cursor follower
* Smooth mouse tracking
* Dynamic fading effect
* Lightweight and simple implementation
* No external libraries

## Built With

* HTML5
* CSS3
* JavaScript

## How It Works

The project tracks the mouse position and dynamically creates small pixel elements around the cursor. Each pixel gradually fades away, creating a smooth trailing effect.

## Usage

Clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/amirsh-dev/pixel-cursor-follower.git
```
